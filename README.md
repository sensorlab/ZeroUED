# SignalSage
Self-supervised specific emitter identification

Mikhail Krasnov, Ljupcho Milosheksi, Mihael Mohorčič and Carolina Fortuna

Paper link: -

# Background

In this paper, we evaluate different approaches to the unknown radio-emitter detection task and propose our own approach. 

Evaluated approaches:
  - Auto Encoders
  - Deep Clustering
  - Classical Sim CLR
  - Viewmaker Sim CLR
  - Viewmaker Sim CLR Large Augs(ours)

We have chosen three datasets for evaluation:
  - Drones Dataset
  - WiSig
  - Lora

# How to start

1. Download the data. For example https://cores.ee.ucla.edu/downloads/datasets/wisig/#/downloads
2. Open evaluations.ipynb and specify the configs, login to wandb, run the experiments
